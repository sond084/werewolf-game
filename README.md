# 狼人殺 334 Online V4

GitHub Pages 使用：
1. 將 `index.html` 上傳到 Repository 根目錄。
2. Settings → Pages → Deploy from a branch → main → /(root)。
3. 等 GitHub 顯示部署完成後開啟網站。
4. 更新後請按 Ctrl+F5 強制重新整理。

V4 主要規則：
- 10 人 334：3 狼、3 神、4 民。
- 真人不足 10 人由 AI 玩家補滿。
- AI 旁白不佔玩家座位。
- 開局每位真人私人抽卡，只看得到自己身份。
- 白天每位存活玩家每輪只發言一次，真人自行按結束發言。
- 全員完成一輪發言後立即投票。
- 只有白天被投票放逐的玩家有遺言。
- 狼刀、女巫毒殺沒有遺言。
- 遺言完成後保留 10 秒給全場閱讀。
